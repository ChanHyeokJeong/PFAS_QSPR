# Raw Data Placement

The raw descriptor and token workbooks are intentionally not committed to this
repository because they are large and may be manuscript-private.

To reproduce runs, place these files in the repository root beside
`masking_benchmark_complete_descriptors.py`:

```text
LogP_descriptor_original.xlsx
PFAS_embedding_numbers.xlsx
BCF_descriptor.xlsx
BCF_PFAS_embedding_numbers.xlsx
```

Optional cache file:

```text
masking_input_cache_logp_endpoint_col4.npz
```
